# Privacy Policy

## Overview
Vertical Shooter S-Rank ("the extension") is a browser-based game designed for entertainment purposes. This extension operates entirely within the user's browser and does not collect or process personal data.

## Data Collection
The extension does **not** collect, store, or transmit any personal information.

- No personal data is collected
- No tracking technologies are used
- No analytics or telemetry is implemented

## Local Storage
The extension may use browser local storage for the following purposes:

- Saving high scores
- Storing game settings (e.g., difficulty, language, preferences)
- Temporary debug logs (if enabled by the user)

All stored data remains on the user's device and is never transmitted externally.

## Data Sharing
The extension does **not** share any data with third parties.

## External Communication
The extension does **not** communicate with any external servers or services.

## Permissions
The extension only uses the minimum permissions required to run the game within the browser environment. It does not access sensitive user data.

## Security
Since no data is transmitted or stored externally, there is no risk of external data leakage from this extension.

## Changes to This Policy
This privacy policy may be updated in the future. Any changes will be reflected in the extension listing.

## Contact
If you have any questions regarding this privacy policy, please contact the developer via the Chrome Web Store listing page.
