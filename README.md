# Vertical Shooter S-Rank

A browser-based vertical shooter game.

## Features
- Rank-based scoring system
- NEW RECORD detection
- Result screen with rank display
- Score sharing (COPY RESULT)
- Local score history (RECENT RUNS)
- Multilingual UI
- BGM support

## Controls
Move: Arrow / WASD  
Shoot: Z / Space / Enter  
Bomb: X  
Slow: Shift  
Overdrive: V
